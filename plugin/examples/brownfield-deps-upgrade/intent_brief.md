# Intent Brief — deps — Upgrade lodash out of CVE-2020-8203

## Context

`lodash@4.17.20` has a known prototype-pollution advisory (CVE-2020-8203). Upgrade to the
smallest version that resolves it. Adapt any code that breaks as a result.

## Goal

- Upgrade `lodash` in `package.json` to a safe version
- Verify `npm audit` reports no more high/critical advisories from lodash
- Existing `config.spec.js` test must still pass — that's the behavior invariant we preserve

## Files in scope

- `package.json` (edit — dep version bump only)
- `src/config.js` (edit — only if the upgrade broke the merge API)
- `src/config.spec.js` (read-only — tests are the invariant)

## Files off-limits

- `src/index.js` — the CVE fix should not require ROUTE-level changes
- `package-lock.json` — regenerated by `npm install`, not hand-edited (the plugin runs
  `npm install` itself)
- Standard set

## Acceptance criteria

- `lodash` version in package.json is >= 4.17.21 (the patched version) or a newer major
- `npm audit --omit=dev` reports zero lodash-related high/critical findings
- `npm test` still passes — behavior of `deepMerge` in config.js is unchanged
- No new deps added (`lodash-es`, `deepmerge`, etc.)

## Non-goals

- Not migrating away from lodash to native / other libs — that's a separate refactor intent
- Not upgrading other dependencies (express, etc.) — one-thing-at-a-time
- Not adding a Dependabot config or CI audit gate — separate concern
