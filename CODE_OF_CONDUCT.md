# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be respectful, be constructive, and assume good faith. Issues and pull requests are for improving the project — not for personal disputes.

Enforcement questions can be raised by emailing the maintainers at `ai-labs-publish-bot@tilicho.in`. Reports are handled in confidence.
